## Downlink 1.1.3

### New
- **Update now.** A new version shows up on the main screen right after Downlink opens. One click downloads it and restarts. Also in Settings, and in the Downlink menu on Mac.

### Fixed
- An update never restarts Downlink in the middle of a download.

Downlink 1.1.1 and later update themselves to this version. Earlier versions need a fresh download.

### Install
- **Mac:** Apple Silicon, macOS 12 or later. Open `Downlink-arm64.dmg` and drag Downlink to Applications.
- **Windows:** 64-bit, Windows 10 or later. Run `Downlink-Setup-x64.exe`. Windows may show a SmartScreen warning because the installer isn't code-signed yet: choose More info, then Run anyway.
